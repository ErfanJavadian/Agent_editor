# راه‌اندازی محیط توسعه Agent Editor

این راهنما برای شاخه بازطراحی ویرایشگر ویدئو نوشته شده است.

## پیش‌نیازها
- Git
- Node.js 20 یا جدیدتر
- npm همراه Node.js

Backend قدیمی برای اجرای پوسته فعلی تدوین لازم نیست. پردازش رسانه و API محلی در milestoneهای بعدی اضافه می‌شوند.

## دریافت شاخه محصول

اگر هنوز مخزن را دریافت نکرده‌ای:

```bash
git clone --branch product/video-editor-pivot https://github.com/ErfanJavadian/Agent_editor.git
cd Agent_editor
```

اگر مخزن را قبلاً دریافت کرده‌ای:

```bash
git fetch origin
git switch product/video-editor-pivot
git pull --ff-only origin product/video-editor-pivot
```

## نصب و اجرای رابط تدوین

```bash
cd frontend
npm install
npm run dev
```

آدرس محلی:

`http://127.0.0.1:5173`

در Android، مرورگر همان گوشی می‌تواند آدرس localhost را باز کند. سرور Vite به‌صورت پیش‌فرض فقط روی loopback گوش می‌دهد.

## اجرای تست‌ها و build

از پوشه `frontend`:

```bash
npm test
npm run typecheck
npm run build
```

تست‌های هسته مشترک در `packages/project-core/tests` و تست‌های IndexedDB در `frontend/tests` قرار دارند؛ اسکریپت Vitest هر دو مجموعه را اجرا می‌کند. در آخرین اجرای CI، هر ۲۰ تست موفق شدند.

## وضعیت محدودیت‌های prototype فعلی

- واردکردن ویدئو/صدا از طریق مرورگر انجام می‌شود.
- فایل‌ها به سرور آپلود نمی‌شوند؛ Blob اصلی در IndexedDB محلی ذخیره می‌شود و URLهای موقت فقط برای پیش‌نمایش همان نشست ساخته می‌شوند.
- پروژه و blob رسانه‌ها در IndexedDB محلی ذخیره می‌شوند؛ بسته قابل‌انتقال بین دستگاه‌ها و relink رسانه هنوز پیاده‌سازی نشده است.
- خروجی MP4، رندر واقعی، چندکلیپی audio mixing، افکت‌ها و undo پایدار هنوز پیاده‌سازی نشده‌اند.
- FPS اولیه sequence برابر 30 است؛ تشخیص دقیق frame rate منبع و تبدیل frame-rate هنوز در دست طراحی است.
- پیش‌نمایش فعلی از قابلیت HTMLVideoElement مرورگر استفاده می‌کند و جایگزین موتور رسانه دسکتاپ نیست.

این محدودیت‌ها باید قبل از اعلام آماده‌بودن نسخه اول برطرف یا مستند شوند.

## بررسی جامع مخزن

از ریشه مخزن، پس از نصب Git، Node.js و Python 3.11 یا جدیدتر، اجرا کن:

```bash
bash scripts/verify-all.sh
```

این اسکریپت:
- سلامت object database مخزن و whitespace diff را بررسی می‌کند.
- وابستگی‌های frontend را نصب و `npm audit` را اجرا می‌کند.
- تمام تست‌های Vitest، بررسی TypeScript و production build را اجرا می‌کند.
- محیط مجازی backend را می‌سازد، وابستگی‌های توسعه را نصب می‌کند و pytest و Ruff را اجرا می‌کند.
- در صورت نصب بودن `pip-audit`، آسیب‌پذیری‌های وابستگی‌های Python را نیز بررسی می‌کند.

برای بررسی‌های دستی روی گوشی، پس از اجرای رابط:
1. یک فایل ویدئویی و یک فایل صوتی وارد کن.
2. هر دو را به ترک مناسب تایم‌لاین اضافه کن.
3. پخش، جابه‌جایی، برش، حذف، Undo و Redo را امتحان کن.
4. صفحه را Refresh کن و بررسی کن پروژه و رسانه‌ها بازیابی می‌شوند.
5. کنسول مرورگر را از نظر خطا بررسی کن.

توجه: این smoke test رابط فعلی را بررسی می‌کند؛ چون موتور رندر واقعی هنوز وجود ندارد، تست خروجی MP4 یا کیفیت رندر در این نسخه ممکن نیست.
