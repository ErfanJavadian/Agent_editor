# Agent Editor

یک محیط خصوصی و محلی برای طراحی، ساخت، آزمایش، مدیریت و ارتقای Agentهای هوش مصنوعی.

> **وضعیت فعلی:** مرحله تثبیت معماری V1. هنوز اجرای نرم‌افزار پیاده‌سازی نشده است.

## هدف و محدوده

Agent Editor ابزار اختصاصی یک کاربر است؛ نه SaaS، نه بازار Agent و نه پلتفرم عمومی. هدف آن فراهم‌کردن یک محیط مهندسی یکپارچه برای کار با Agentها و ابزارهای آن‌هاست.

## اصول طراحی

- **Local-first:** داده‌ها و تنظیمات به‌صورت پیش‌فرض روی دستگاه خود کاربر نگهداری می‌شوند.
- **Provider-agnostic:** اتصال مدل‌ها پشت یک لایه مشترک قرار می‌گیرد تا وابستگی به یک ارائه‌دهنده ایجاد نشود.
- **Modular:** هسته، مدل‌ها، ابزارها، مهارت‌ها، حافظه و رابط کاربری مرزبندی مشخص دارند.
- **Approval-first:** عملیات حساس و دارای اثر بیرونی نیازمند تأیید صریح هستند.
- **Observable:** هر اجرا باید وضعیت، رویدادها، خطاها و مصرف منابع قابل بررسی داشته باشد.
- **Mobile-conscious:** رابط وب باید روی نمایشگر موبایل قابل استفاده باشد؛ اجرای محلی روی Android/Termux نیز در تصمیم‌های فنی لحاظ می‌شود.

## مسیر کلی

1. تثبیت معماری و قراردادهای ماژول‌ها
2. ایجاد اسکلت قابل اجرا و تنظیمات محلی
3. پیاده‌سازی هسته Agent و اجرای کنترل‌شده
4. اضافه‌کردن مدل‌ها، ابزارها، مهارت‌ها و حافظه

## اصل امنیت

کلیدهای API، فایل‌های حافظه، پایگاه داده و خروجی اجرا نباید وارد Git شوند. سرور محلی در حالت پیش‌فرض فقط روی `127.0.0.1` گوش می‌دهد. اجرای فرمان سیستم، حذف/تغییر فایل و هر عملیات بیرونی باید با مجوز محدود و در صورت نیاز با تأیید کاربر انجام شود.
