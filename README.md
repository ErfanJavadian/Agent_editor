# Agent Editor

**Agent Editor** یک ویرایشگر حرفه‌ای ویدئو با معماری AI-native و پشتیبانی هدفمند از دسکتاپ، وب و اندروید است. کاربر می‌تواند با تایم‌لاین و ابزارهای دقیق به‌صورت دستی تدوین کند یا با دستور طبیعی، یک گردش‌کار تدوین را به ایجنت بسپارد و قبل از اعمال تغییرات آن را بررسی و تأیید کند.

> وضعیت فعلی: prototype مرورگری برای واردکردن و ذخیره محلی رسانه، بازیابی پروژه، پیش‌نمایش و عملیات پایه تایم‌لاین موجود است. قراردادهای مستقل Media Engine و اعتبارسنجی درخواست رندر نیز اضافه شده‌اند؛ اما هنوز هیچ decoder/encoder واقعی یا خروجی MP4 متصل نیست. قابلیت‌ها فقط پس از CI و بررسی دستگاه هدف تأییدشده اعلام می‌شوند.

## چشم‌انداز محصول

- **Desktop (Windows/Linux):** محیط مرجع برای تدوین حرفه‌ای، تایم‌لاین چندترکی، صدا، افکت، رنگ، موشن و رندر.
- **Web:** مشاهده و مدیریت پروژه، بازبینی، تدوین سبک و گردش‌کارهای ایجنتی با رعایت محدودیت مرورگر.
- **Android:** تدوین لمسی، واردکردن رسانه، بازبینی، زیرنویس و عملیات سریع متناسب با سخت‌افزار موبایل.
- **AI Agent System:** تحلیل پروژه، ساخت برنامه تدوین، پیشنهاد تغییرات ساختاریافته، اعتبارسنجی، تأیید انسانی، اعمال و امکان بازگشت.

سه کلاینت باید از فرمت پروژه نسخه‌دار و معناشناسی مشترک تدوین استفاده کنند؛ برابری کامل امکانات بین پلتفرم‌ها هدف نسخه اول نیست.

## اصول غیرقابل‌مذاکره

- تدوین غیرمخرب؛ فایل اصلی رسانه با عملیات معمول تایم‌لاین تغییر نمی‌کند.
- زمان‌بندی مبتنی بر فریم/تیک صحیح؛ بدون خطای تجمعی floating point.
- پروژه قابل‌انتقال با نسخه‌بندی و مهاجرت صریح.
- عملیات تایم‌لاین قطعی، اعتبارسنجی‌شده و قابل بازگشت.
- ایجنت فقط از ابزارهای تدوین محدود و نوع‌دار استفاده می‌کند؛ نه shell آزاد.
- تغییرات ایجنت قبل از اعمال قابل بازبینی هستند.
- رسانه‌ها به‌صورت پیش‌فرض محلی می‌مانند؛ پردازش ابری اختیاری و با رضایت کاربر است.
- قابلیت‌ها فقط پس از تست و بررسی دستگاه هدف «تأییدشده» اعلام می‌شوند.

## معماری

- `frontend/`: React + TypeScript؛ prototype تعاملی مرورگری با media bin، preview، تایم‌لاین دوترکی، ذخیره‌سازی IndexedDB، Drag & Drop و میانبرهای صفحه‌کلید.
- `packages/project-core/`: مدل نسخه‌دار پروژه، parser/serializer، اعتبارسنجی و عملیات immutable تایم‌لاین.
- `packages/browser-project-store/`: ذخیره محلی manifest و Blob رسانه در IndexedDB.
- `packages/media-engine/`: قراردادهای مستقل پلتفرم برای probe/render و اعتبارسنجی قابلیت‌ها و درخواست خروجی؛ هنوز backend اجرایی ندارد.
- `backend/`: زیرساخت محلی و APIهای اختیاری؛ هنوز موتور رسانه نیست.
- `docs/`: تعریف محصول، معماری و نقشه راه.
- `desktop/` و `android/`: کلاینت‌های اختصاصی در مراحل بعدی اضافه می‌شوند.

## قاعده پیشرفت

- **Planned:** طراحی شده، اما کد ندارد.
- **Implemented:** کد اضافه شده، ولی تست کامل یا دستگاه هدف تأیید نشده است.
- **Verified:** تست‌های مرتبط و بررسی اجرایی لازم موفق بوده‌اند.

هیچ‌وقت صرفاً با ساختن فایل یا سند، قابلیت را تکمیل‌شده گزارش نمی‌کنیم.
